# Wi-Fi 实验记录

Wi-Fi 调试已按使用者要求暂停；尚未验证可用无线网络。

- 原厂使用 PCIe W2 / w2_comm 路径，不能用借用 DTB 中的 SDIO 节点推断硬件。
- 原厂 4.9 ARM32 模块不能直接装入当前 6.12 ARM64 内核。W2 源码已在本地适配并编译出两个 ARM64 模块；轻量公共模块曾加载、卸载成功，但不等于 Wi-Fi 工作。
- USB2 单项启动测试曾通过；加入 PCIe 的两版组合测试出现花屏及 SSH 丢失，已回退。
- `dts/c10h-wifi-pcie-test.dtso` 仅归档失败方向；GPIO/共享 PHY 配置仍待验证，不是可直接安装的驱动。
- 本次不上传固件、原厂模块或大型第三方驱动源码。下一步首先解决 PCIe 枚举和共享资源配置，再验证驱动、固件、连接与重启。
