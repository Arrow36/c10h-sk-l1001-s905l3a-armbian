# C10H 上的 fnOS 内屏实验

> **系统范围更正（设备使用者确认）**：fnOS 内屏已实测显示正常；Armbian 内屏尚未测试。下文涉及 Armbian 显示效果或 FbTerm 的历史叙述仅保留作溯源，不作为已测试结论。

> **历史记录**：正文保留当时的观察、配置和下一步任务。11 月 6 日记录报告寄存器调整后几何、明显偏色和抽动改善；当前状态与限制见 [寄存器调整记录](research/fnos-display-resolution-record-2026-11-06.md)。本文不作为当前安装步骤。

2026-11-04 · 创维 C10H / SK-L1001 · Amlogic S905L3A · JD9366TC，800×1280，四通道 MIPI DSI RGB888。

非官方 ARM fnOS 1.1.20（Debian 12，Linux `6.12.41-trim #219`）已从 U 盘启动，有线 SSH 和 Web 管理页可用。实验设备树禁用了 eMMC，原厂 Android 保留在内部存储。C10H DSI 主机和面板驱动针对目标内核重新编译。禁用 HDMI 后，`DSI-1` 独占 CRTC，内屏开机自动点亮并运行在 800×1280@60 Hz。初期曾有画面分区、重复与闪动，后续改善情况见 11 月 6 日记录。

## 四种图像来源的对照（11 月 4 日故障阶段）

| 图像来源 | 实测结果 |
| --- | --- |
| DRM 线性 XR24 缓冲区，800×1280，pitch 3200 | 原子图层提交成功并恢复原 framebuffer。屏幕左侧为固定色块，右侧边框、横线和方块重复。 |
| 向 `/dev/fb0` 写全白 | 右侧变白，左侧保持紫色。CPU 读回 4,096,000 字节，九点取样均为白色。 |
| OSD1 短时强制白色 | 右侧变白，左侧仍紫。测试结束后读回原控制值。 |
| ENCL 内部彩条 | 彩条完整，无可见重复或错位。 |

Canvas 读回地址与当次 DRM DMA 地址一致，行跨度 3200 字节、高度 1280 行，OSD/Blend 窗口也与模式相符。这些是配置和 CPU 侧证据，尚未确认硬件实际读取的逐像素数据。OSD1 强制白色复现了相同的空间分区，使排查重点进一步收敛到 OSD1 实际覆盖、Blend/VPP 到 ENCL 的普通像素输入。彩条验证了内部图案可以完整输出，普通像素流的时序与路由仍需对照。

浏览器滑杆测出可响应区域的颜色循环为红→绿、绿→蓝、蓝→红。软件逆置换能补偿测试图颜色。白色在通道置换下保持不变，因此仍需单独解释左侧紫色区域。见[浏览器诊断方法](display-browser-diagnostics.md)。

## 运行状态和单变量实验

| 检查 | 观察及边界 |
| --- | --- |
| OSD1 FIFO、AFBC | FIFO 常见读数为 `0x028207E1`。监测中短暂出现 `0x029207E1`，现有采样不足以判定欠载。未见 AFBC 被错误启用的直接证据。 |
| OSD/VPP 当前坐标与 ENCL 状态 | OSD Blend 当前 XY 为 `0x00040000`，VPP Postblend 当前 XY 为 `0x00000000`，ENCL 状态持续变化。前两项固定值的运行时含义仍待核对。 |
| VD1 旧 Postblend 位 | 短时清除后画面无可见变化，随后恢复原值。 |
| VPP 保持行数 | 短时将前后混合保持行数由 4 改为 8，画面无可见变化，随后恢复原值。 |
| DSI 与 Gamma | 驱动报告实际位时钟 531 MHz、像素时钟约 75.857 MHz，模式目标为 76.107 MHz。抽查 DSI 错误状态为零。开机仍有 Gamma 写入和寻址就绪超时，尚未建立与空间分区的因果关系。 |
| framebuffer 接管 | 两处 simplefb 节点均禁用，`/proc/fb` 只有 `mesondrmfb`。 |

## 与 Armbian 的对照

早期记录称 Armbian `6.12.114-ophub` 可显示完整边框与十字，但与设备使用者后续确认的“Armbian 内屏尚未测试”冲突。该说法保留为历史来源线索，不作为已测事实；本轮不能确定其实际测试归属，见 [审计冲突说明](audit.md#材料冲突与处理)。两边的位时钟与像素时钟报告接近。公开 Linux `v6.12.41`、`v6.12.114` 中检查的 10 个 Meson 显示驱动文件哈希相同，实际运行的定制内核仍需结合构建配置、补丁和外部模块核对。已检查的设备树属性差异中未发现 VPU 主节点被意外改写。CMA、fbdev 分配比例及 PHY 模块配置存在候选差异，尚无因果验证。见 [显示概览与历史过程](display.md)与[后续实测](display-followup.md)。

下一轮先确认已安装模块的构建来源，再用相同图案、输出模式和采样口径对比两套系统。可用预绘制的非等距横带和竖带标记坐标，区分行重复、列重复和固定覆盖边界。版本指纹用于识别二进制，源码归属需结合明确提交及构建记录。
