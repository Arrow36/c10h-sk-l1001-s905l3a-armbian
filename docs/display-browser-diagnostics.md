# C10H 浏览器显示诊断方法

本轮用两种工具观察 [fnOS 内屏实验](display-fnos.md)。两者均在 C10H 上运行，HTTP 服务绑定回环接口，操作者通过 SSH 本地端口转发访问并直接观察实体屏幕。

## 像素刺激滑杆

浏览器发送方块坐标、RGB 和背光设置，Python 服务经共享映射写入 `/dev/fb0`。后续版本增加 RGB 循环补偿及全屏纯色模式。工具检查实验画面为 800×1280、32 bpp、stride 3200，并在正常停止或浏览器断线超时后尝试恢复原 framebuffer 和背光。

| 操作 | 观察 |
| --- | --- |
| 逐一切换红、绿、蓝 | 可响应区域依次显示绿、蓝、红。fbdev 仍报告 R16/G8/B0。 |
| 将小端 XR24 测试像素由 `(B,G,R,0)` 改为 `(R,B,G,0)` | 测试图颜色可补偿，固定紫色区域和重复仍在。 |
| 切换全白并读取 framebuffer | 右侧变白，左侧不变。CPU 读回支持整帧几乎全白。原统计按字节序列匹配，精确的非白像素数应按四字节像素边界复核。 |

滑杆让操作者能快速关联输入和实屏变化。需要精确比对几何时，可用预绘制的独立 DRM 缓冲区保持画面静止，减少控制台并发写入和重绘对观察的影响。

## 只读寄存器监测

独立监测工具定时读取固定的 ENCL、OSD、VPP 寄存器，网页显示趋势、支持记录现场标记并导出 CSV。监测过程不写 framebuffer、背光或显示寄存器。以下为实机 CSV 的聚合结果。

| 指标 | 结果 |
| --- | --- |
| 采样范围 | 186 行，首尾间隔 138.449 秒，0 行记录采样错误 |
| ENCL 状态 | 186 个不同值 |
| OSD Blend 当前 XY | `0x00040000`，186 行 |
| VPP Postblend 当前 XY | `0x00000000`，186 行 |
| OSD1 FIFO | `0x028207E1` 178 行，`0x029207E1` 8 行 |

慢速寄存器的最近读数会在多行复用。FIFO 中 8 行不同值不能按 8 次独立事件计数，bit20 的变化也不足以判定欠载。下次记录可给每组寄存器保留独立的读取序号和单调时间，并给每次图案切换或实屏观察打标记，使 CSV 能区分实际读取和缓存复用。
