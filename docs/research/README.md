旧项目 URL、设备绝对路径、照片名、ZIP/CSV/DTB/模块路径是历史引用，不表示当前仓库提供那些附件。缺失材料见 [证据索引](../../evidence/README.md)。当前源码与配置值看 [显示概览](../display.md)，不直接照抄研究日志中的临时写入命令。
